# AI 웹소설 연재관

![AI 웹소설 연재관 안내 이미지](./og-novel.png)

세 작품의 새로운 이야기를 별도 설치 없이 브라우저에서 바로 읽을 수 있는 웹소설 연재관이다. 작품을 고르고 첫 화부터 정주행하거나 최신 공개 회차부터 이어서 읽을 수 있다.

**[AI 웹소설 연재관에서 바로 읽기](https://plcmanjp.github.io/novel/)**

## 연재 작품

### [허상의 경계](https://plcmanjp.github.io/novel/#/s/hollow-observer)

현대 판타지, 오컬트, 다크 판타지

보이지 않는 균열을 감지하는 소년이 세계의 정의를 지우는 힘과 마주하는 다크 오컬트 판타지다.

### [서툰 계절의 끝에서](https://plcmanjp.github.io/novel/#/s/awkward-season)

러브코미디, 로맨스, 학원물

어릴 적 가장 가까웠던 두 사람이 고등학교에서 다시 서로의 거리와 마음을 알아가는 청춘 로맨스다.

### [잿불의 검](https://plcmanjp.github.io/novel/#/s/ash-blade)

정통 판타지, 성장물, 모험

모든 것을 잃은 소년 카엘이 검과 동료를 붙잡고 잿빛 세계를 헤쳐 나가는 정통 성장 판타지다.

## 읽는 방법

1. 연재관에서 원하는 작품을 선택한다.
2. 처음부터 읽으려면 `1화부터`, 새 이야기를 확인하려면 `최신화 읽기`를 선택한다.
3. 본문 아래의 `이전화`, `목록`, `다음화`로 회차를 이동한다.

공개된 회차만 목록에 표시된다. 회차 번호가 이어지지 않는 구간에서도 이전화와 다음화 버튼은 실제 공개 순서에 맞춰 이동한다.

## 편안하게 읽기

- 라이트 테마와 다크 테마를 전환할 수 있다.
- 회차 화면의 읽기 설정에서 글자 크기와 줄 간격을 조절할 수 있다.
- 선택한 테마와 읽기 설정은 현재 브라우저에 저장된다.
- 데스크톱과 모바일 브라우저에서 같은 작품과 회차를 읽을 수 있다.

## 모바일 화면

작은 화면에서도 작품 정보와 본문을 한 흐름으로 읽고 상단 버튼에서 테마와 읽기 설정을 바꿀 수 있다.

![모바일 웹소설 회차 읽기 화면](./reader-mobile.png)

## 이용 안내

- 새 회차가 공개되면 작품 목록과 최신화가 자동으로 갱신된다.
- 작품 목록이나 본문이 보이지 않으면 브라우저에서 JavaScript가 켜져 있는지 확인한다.
- 모든 회차는 AI가 생성한 창작물이다.
