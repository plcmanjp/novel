# AI 웹소설 연재관

매일 이어지는 세 작품을 브라우저에서 바로 읽는 정적 웹소설 리더다.

## 구성

- `index.html`, `app.js`, `styles.css`: 공개 리더
- `data/index.json`: 작품 목록
- `data/series/<series_id>/meta.json`: 작품별 메타데이터
- `data/series/<series_id>/episodes/*.json`: 공개 회차

회차 번호는 연속이라고 가정하지 않는다. 공개 데이터에 없는 번호를 임의로 생성하거나 복원하지 않는다.

## 자동 게시

004 Discord 봇이 새 회차와 작품 메타데이터, 작품 목록을 한 Git 커밋으로 갱신한다. 공개 payload만 저장하며 내부 기억, 프롬프트, 토큰과 운영 로그는 포함하지 않는다.

## 로컬 확인

정적 파일 서버로 저장소 루트를 열고 작품 목록, 회차 이동, 테마와 읽기 설정을 확인한다. `file` 경로 직접 열기보다 HTTP 정적 서버를 사용한다.
